Second Differences (Interaction Effects)

Quantifying how marginal effects vary across moderator levels

Quick Start

One function covers every case. Give it the fitted model, the data, the focal variable(s) and the moderator:

second_differences(model, data, :age, :treated)             # discrete modifier: treated vs not
second_differences(model, data, [:age, :income], :treated)  # several focal variables
second_differences(model, data, :age, :income)              # continuous modifier: average ∂AME/∂income over the observed incomes
second_differences(model, data, :age, :income; at=[20_000, 50_000])      # at chosen values
second_differences(model, data, :age, :income; levels=[20_000, 50_000])  # slope between two values
second_differences(model, data, :age, :treated; profile=(female=[0, 1],)) # with everyone's female set to 0, then 1
second_differences(model, data, :age, :treated; vcov=HC1())              # robust covariance

The modifier type is detected from the data (Bool, 0/1, two-valued, string or categorical → discrete; numeric with more than two distinct values → continuous); use modifier_type=:categorical for an integer-coded categorical modifier. Scenarios, AMEs and delta-method standard errors are handled internally. vcov takes the same forms as in population_margins and defaults to GLM.vcov.

If you already hold an EffectsResult from population_margins(...; scenarios=..., type=:effects), the same comparison is available on its rows, with vcov defaulting to the covariance the result was computed with:

ames = population_margins(model, data; scenarios=(treated=[0, 1],), type=:effects)
sd = second_differences(ames, :age, :treated)

Conceptual Foundation

What Are Second Differences?

Second differences measure whether the marginal effect of one variable differs across levels of another variable. In generalized linear models, where effects are inherently nonlinear, second differences provide the natural way to quantify interaction effects on the predicted outcome scale.

Definition: For two variables X (focal variable) and Z (moderator), the second difference is defined as:

\[\Delta^2 = [E(Y|X=1,Z=1) - E(Y|X=0,Z=1)] - [E(Y|X=1,Z=0) - E(Y|X=0,Z=0)]\]

This represents the difference in marginal effects, a "difference of differences", capturing how the effect of X changes when Z changes.

Relationship to Interaction Terms

Model TypeLinear ModelNonlinear Model (GLM)
Simple effectCoefficient on XMarginal effect of X
InteractionCoefficient on X × ZSecond difference
ScaleCoefficient scale = outcome scaleMust compute from predicted probabilities/means

In linear models, the interaction coefficient directly represents the second difference. In nonlinear models (logit, probit, Poisson), the interaction coefficient does not directly represent the interaction on the predicted scale, necessitating explicit computation of second differences from marginal effects.

Methodological Context

Second differences extend the conceptual framework of Margins.jl by addressing a fundamental question: "Does the effect of X depend on Z?" This complements the two core questions of marginal effects analysis:

  1. Effects: "How much does Y change when I change X?"
  2. Predictions: "What value of Y should I expect?"

Second differences answer: "Does the answer to question 1 change depending on Z?"

Computational Framework

Two Ways to Compare, One Function

second_differences(model, data, variables, modifier; …) chooses the computation from the modifier:

Discrete comparison (population-based)

For a discrete modifier (Bool, 0/1, two-valued, string or categorical), or a continuous modifier with explicit levels, Margins.jl computes the population AME of the focal variable with every observation's modifier set to each level, and differences them. This provides:

  • Population representativeness: effects averaged over the sample distribution
  • Statistical validity: delta-method standard errors that use the covariance between the AMEs
  • All pairs: K levels give K(K−1)/2 comparisons; categorical focal variables add one row per contrast

Local derivative (finite differences)

For a continuous modifier, second_differences computes ∂AME/∂modifier at the at points by a symmetric finite difference, (AME(at + δ) − AME(at − δ)) / 2δ, with the other variables in profile held fixed. This provides:

  • A rate: the change in the marginal effect per unit of the modifier
  • Profile control: evaluate at chosen values of the modifier and other variables
  • Requirement: the modifier must be numeric (the focal variable may be continuous or categorical)

Statistical Inference

Standard errors use the delta method. For a second difference comparing two AMEs with parameter gradients g₁ and g₂:

\[\text{SE}(\Delta^2) = \sqrt{(g_2 - g_1)' \Sigma (g_2 - g_1)}\]

where Σ is the covariance matrix of the parameters (the vcov you choose). The formula accounts for the covariance between the two AME estimates and propagates the full parameter uncertainty. For a continuous modifier the estimate, standard error and gradient are divided by the modifier distance.

The test statistic is statistic = second_diff / se. Its reference distribution is recorded in the df column, by the same rule as the rest of the package, whatever covariance is used: t with df = dof_residual(model) for a linear model (lm, or a Gaussian identity-link glm) and a FixedEffectModels fit, and z (df = Inf) for every other model; the df keyword overrides it (see Inference).

Output Schema

Every second-difference function returns the same columns, in this order, whatever the modifier type:

columnmeaning
variablefocal variable (Symbol)
contrastfocal contrast ("dy/dx" for a continuous variable, "B - A" for levels)
modifiermodifier variable (Symbol)
modifier_type:binary, :categorical or :continuous (always filled)
modifier_level1, modifier_level2modifier values compared (numeric levels ascending; categorical levels in level order)
ame_at_level1, ame_at_level2focal effect at each modifier value
second_diffame_at_level2 - ame_at_level1; for :continuous, divided by the modifier distance (a slope)
sedelta-method standard error
statisticsecond_diff / se
dfdegrees of freedom of the reference distribution (Inf = z)
p_valuetwo-sided p-value for H₀: second difference = 0 (NaN for a second difference that is zero by construction)
ci_lower, ci_upper(1 − alpha) confidence interval for second_diff, from the same t/z reference as the test
significantp_value < alpha (p_adjusted < alpha when p_adjust is set)

A local derivative adds eval_point and delta_used (with modifier_type = :continuous, modifier_level1/2 = eval_point ∓ delta_used, and second_diff the derivative ∂AME/∂modifier), groups= adds one over_<var> column per grouping variable, and every profile variable adds one column (in that order). With p_adjust set, a p_adjusted column follows p_value; significant uses it, but ci_lower/ci_upper stay unadjusted. With include_gradients=true, a gradient column (the vector ∂second_diff/∂β, for custom variance calculations) follows the schema columns; as in DataFrame(result) it is omitted by default, so the table has only scalar columns and exports cleanly. The column names are also available as Margins.SECOND_DIFFERENCE_COLUMNS.

The example outputs on this page are illustrative; the numbers are not from a particular data set.

Function Reference

second_differences(model, data, variables, modifier; …)

The main entry point. It builds the scenarios, computes the AMEs and applies the delta method.

second_differences(
    model::RegressionModel, data,
    variables::Union{Symbol, Vector{Symbol}}, modifier::Symbol;
    levels = nothing, at = nothing, modifier_type::Symbol = :auto,
    profile::NamedTuple = NamedTuple(), groups = nothing, delta = :auto,
    scale::Symbol = :response, measure::Symbol = :effect, contrasts::Symbol = :baseline,
    contrast = nothing, vcov = GLM.vcov, df = nothing, weights = :model, alpha = 0.05,
    p_adjust::Symbol = :none, include_gradients::Bool = false, warn::Bool = true, backend::Symbol = :ad,
)

Arguments:

  • model, data: the fitted model and the data frame it was fit to
  • variables: focal variable(s), continuous or categorical; must not include the modifier
  • modifier: the moderating variable

Keyword arguments:

  • levels: modifier values to compare. Default for a discrete modifier: all its levels (a categorical array's level order, except that numeric levels are always ascending; otherwise sorted). For a continuous modifier, levels returns slopes (AME₂ − AME₁)/(m₂ − m₁) for every pair of the given values
  • at: continuous modifier only; where to take the derivative: :observed (default), :mean, :median, a number, a vector of numbers, or a NamedTuple containing the modifier plus other variables to hold fixed. Cannot be combined with levels. at=:observed (the default) is the average derivative over the observed values (see below)
  • modifier_type: :auto (default), :categorical or :continuous. Detected from the data: numeric with more than two distinct values → continuous; Bool, 0/1, two-valued, strings, categorical arrays → categorical. A numeric modifier with at most 5 distinct integer values is treated as continuous with a warning (unless at or levels is given), because it is often a coded category. Override with modifier_type=:categorical for an integer-coded categorical modifier
  • profile: other variables to hold fixed, e.g. (age=40, region="north"); vector values give one profile point each (Cartesian product, counterfactual rather than subgroup) and appear as extra columns
  • groups: strata, with the syntax of population_margins (:region, [:region, :sex], (:income, 4) quartiles, (:income, [cut1, cut2]) thresholds, :region => :sex nested). The second difference is computed within each stratum, from that stratum's rows only, and each stratum is a block of rows with over_<var> columns (in the order of groups, after the schema columns and before the profile columns). See Counterfactual and subgroup second differences
  • weights: observation weights as in population_margins: :model (default; the weights the model was fit with, if any, otherwise none), :none (or nothing) for unweighted, a column name or a vector. All average marginal effects are weighted, and at=:mean/:median use the weighted mean/median of the modifier. So glm(…; wts = w) gives weighted second differences without further arguments; pass weights = :none for the unweighted ones (the 2.x default). The table records the source as metadata(sd, "weights_source") (:model, :user or :none). See Weights for how each model class is read and for the standard errors (from vcov, not design-based). For a result you already hold, pass the weighted EffectsResult to the result-level form: its gradients carry the weights
  • delta: finite-difference step for a local derivative (:auto = 1% of the modifier's SD, raised where needed to keep at ± δ distinct in floating point); ignored with levels
  • measure: :effect (default), :elasticity, :semielasticity_dyex or :semielasticity_eydx, as in population_margins; the second difference is then the change in that measure across the modifier (the ame_at_level1/2 columns hold the measure). These are defined for continuous focal variables only, so request categorical variables in a separate call
  • scale: :response or :link; backend: :ad (default) or :fd for the derivatives of continuous focal variables, as in population_margins
  • contrast: restrict the result to one contrast label, e.g. "college - hs" or "dy/dx"; default nothing keeps every contrast. Applies to every focal variable and must exist under the chosen contrasts
  • contrasts: :baseline (K−1 contrasts per categorical focal variable) or :pairwise (K(K−1)/2)
  • vcov: covariance estimator, as in population_margins: a function of the model (GLM.vcov, the default), a matrix (any AbstractMatrix, e.g. Symmetric), or a CovarianceMatrices estimator (HC1()). It is evaluated once per call; df overrides the t/z degrees of freedom, as in population_margins
  • alpha: as in population_margins (default 0.05). ci_lower/ci_upper are the (1 − alpha) interval and significant is p_value < alpha, so alpha=0.1 gives 90% intervals
  • p_adjust: multiple-testing adjustment over all rows returned, i.e. every variable, contrast, level pair, evaluation point, profile point and groups stratum: :none (default), :bonferroni, :holm (family-wise error rate) or :bh (Benjamini–Hochberg false-discovery rate). It adds a p_adjusted column after p_value and bases significant on it. Rows that are zero by construction (see When the model cannot support the calculation) are not tests: they have no p-value and are left out of the family
  • include_gradients: add a gradient column (∂second_diff/∂β per row); omitted by default, as in DataFrame(result)
  • warn: true (default) gives one warning per call about second differences that are zero by construction and about modifier or profile values outside the observed range; see When the model cannot support the calculation. warn=false silences both without changing any number

Returns: a DataFrame with the output schema.

Cost: one population_margins call per profile point for a comparison of levels, and one per evaluation point and profile point (two modifier values each) for a local derivative; groups strata are computed in the same call (with at=:mean/:median, one call per stratum, since each stratum has its own evaluation point).

Errors are ArgumentErrors for every invalid input (an unknown column, a bad alpha, at, delta, p_adjust, levels or contrast label, a modifier in profile or groups), as in population_margins.

second_differences(result, variables, modifier; …)

The same comparison on the rows of an EffectsResult you already hold: from population_margins(...; scenarios=(modifier=levels,), type=:effects) (differences of AMEs) or from profile_margins(model, data, cartesian_grid(modifier=levels); type=:effects) (differences of marginal effects at the profile; the grid may vary the modifier only). A PredictionsResult is rejected with a message pointing to type=:effects.

second_differences(
    ame_result::EffectsResult,
    variables::Union{Symbol, Vector{Symbol}},
    modifier::Symbol;
    contrast = nothing,
    modifier_type::Symbol = :auto,
    alpha = nothing,
    p_adjust::Symbol = :none,
    include_gradients::Bool = false,
    warn::Bool = true,
)
  • The standard errors use the covariance matrix the result was computed with, and df its degrees of freedom (result.inference), so they agree with those of the AMEs. For a different estimator, compute the result with vcov=… (or call the model-level form with vcov=…). Margins 2.x took a matrix as a fourth argument; that is now an error.
  • The result must vary over the modifier and, optionally, groups= variables. Each combination of the groups variables (other than the modifier) is a stratum: the modifier levels are paired within it, and the stratum's rows carry over_<var> columns. If another scenario variable also varies across the rows, the function raises an error instead of pairing rows from different cells. With groups=modifier (and no scenarios) the comparison is across the observed subgroups of the modifier: the subgroup second difference (see below).
  • modifier_type: :auto classifies two levels as :binary (with a warning if they are numeric and not 0/1, because the result is then the raw AME difference rather than a slope), three or more numeric levels as :continuous, otherwise :categorical.
  • contrast: nothing (default) uses every contrast of each focal variable; a label such as "college - hs" or "dy/dx" restricts the result to that contrast. (Plural contrasts= in the model-level form chooses how contrasts are built, :baseline or :pairwise; a result already holds its contrasts.)
  • alpha defaults to the value the result was computed with; p_adjust and include_gradients are as above.
  • Numeric (and Bool) modifier levels are always compared in ascending order, so modifier_level1 < modifier_level2 whatever the scenario order; categorical levels keep scenario order.

Migrating from Margins 2.x

Margins 3.0 has one function, second_differences, in the two forms above. The functions of 2.x are removed (calling one raises an UndefVarError that names its replacement):

Removed (2.x)Use instead
second_differences_at(model, data, vars, mod, vcov; at=…, …)second_differences(model, data, vars, mod; at=…, vcov=vcov, …)
second_differences_pairwise(result, var, mod, vcov; contrast=…)second_differences(result, var, mod; contrast=…)
second_differences_all_contrasts(result, var, mod, vcov)second_differences(result, var, mod)
second_differences_table(result, vars, mod, vcov)second_differences(result, vars, mod)
second_difference(result, var, mod, vcov) (a NamedTuple)second_differences(result, var, mod; include_gradients=true) (one DataFrame row)

Other differences from 2.x: the result-level form takes no vcov (it uses the covariance matrix the result was computed with, result.inference.vcov; pass vcov= to population_margins or profile_margins to change it); output tables no longer include a gradient column unless include_gradients=true; there are new ci_lower/ci_upper columns; the local derivative is in second_diff (it was derivative); and a numeric modifier's levels are always compared in ascending order. See the CHANGELOG for the full list.

Usage Patterns

Basic Workflow

using Margins, GLM, DataFrames

# Fit a model with the interaction, then ask how the effect of x varies with `treated`
model = lm(@formula(y ~ x * treated + z), data)
sd = second_differences(model, data, :x, :treated)

Output structure:

1×17 DataFrame (selected columns)
 Row │ variable  contrast  modifier  modifier_type  modifier_level1  modifier_level2  second_diff  se       statistic  df       p_value  significant
     │ Symbol    String    Symbol    Symbol         Int64            Int64            Float64      Float64  Float64    Float64  Float64  Bool
─────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   1 │ x         dy/dx     treated   binary                       0                1        0.152   0.0428       3.55    496.0   0.0004  true

Interpretation: the marginal effect of x is 0.152 units larger when treated=1 than when treated=0 (p < 0.001), a significant positive interaction. In a linear model without other interactions this equals the coefficient on x & treated.

Binary Moderators

A binary moderator gives one second difference per focal variable and contrast.

# Does the effect of age vary by treatment status?
model = glm(@formula(outcome ~ age * treated + education), data, Binomial(), LogitLink())
sd = second_differences(model, data, :age, :treated)
  • Positive: the effect is stronger when treated
  • Negative: the effect is weaker when treated
  • Near zero: the effect is homogeneous across treatment status

Categorical Moderators

A moderator with K levels gives K(K−1)/2 pairwise comparisons.

# Does the income effect vary across education levels?
model = lm(@formula(consumption ~ income * education), data)
sd = second_differences(model, data, :income, :education)
3×17 DataFrame (selected columns)
 Row │ variable  modifier   modifier_type  modifier_level1  modifier_level2  second_diff  se       statistic  df       p_value  significant
     │ Symbol    Symbol     Symbol         String           String           Float64      Float64  Float64    Float64  Float64  Bool
─────┼──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   1 │ income    education  categorical    hs               college                0.152    0.042       3.62    994.0   0.0003  true
   2 │ income    education  categorical    hs               grad                   0.243    0.051       4.76    994.0   <1e-5   true
   3 │ income    education  categorical    college          grad                   0.091    0.048       1.90    994.0   0.058   false

The effect of income is 0.152 higher for college than for high-school graduates (p < 0.001); the college-to-grad increase (0.091) is not statistically significant. For a plain string column the levels are compared in sorted order; for a CategoricalArray they follow its level order. Use levels=["hs", "grad"] to compare a subset.

Continuous Moderators

For a continuous modifier the default is the average derivative over the observed values (at=:observed):

model = lm(@formula(outcome ~ treatment * age), data)

second_differences(model, data, :treatment, :age)                        # average ∂AME/∂age over the observed ages
second_differences(model, data, :treatment, :age; at=:mean)              # at the mean age, set for everyone
second_differences(model, data, :treatment, :age; at=[30, 45, 60])       # at three ages
second_differences(model, data, :treatment, :age; levels=[30, 45, 60])   # slopes between the three ages
  • second_diff: the change in the marginal effect per unit increase in the moderator
  • With levels, the comparison 30→45 gives (AME₄₅ − AME₃₀) / 15; with at, the value is the derivative at each point
  • Positive slopes mean the effect strengthens as the moderator increases

Multiple Focal Variables

# Which demographic effects vary most by treatment?
model = lm(@formula(outcome ~ (age + education_yrs + experience) * treated), data)
sd = second_differences(model, data, [:age, :education_yrs, :experience], :treated)

Categorical Focal Variables

A categorical focal variable gives one row per contrast and modifier comparison.

using CategoricalArrays
data.education = categorical(data.education; levels=["hs", "college", "grad"])

model = lm(@formula(income ~ education * region), data)

# Baseline contrasts (college − hs, grad − hs) × region pairs
sd = second_differences(model, data, :education, :region)

# All pairwise contrasts (adds grad − college)
sd = second_differences(model, data, :education, :region; contrasts=:pairwise)

With three education levels and three regions, contrasts=:baseline (the default) returns 2 × 3 = 6 rows and contrasts=:pairwise returns 3 × 3 = 9 rows. To look at one contrast, filter the result: contrast="college - hs" (or filter the result, sd[sd.contrast .== "college - hs", :]).

Local Derivatives at Profiles

# Does the income effect on consumption strengthen or weaken with age?
model = lm(@formula(consumption ~ income * age + education), data)

second_differences(model, data, :income, :age)                           # averaged over the observed ages
second_differences(model, data, :income, :age; at=[25, 35, 45, 55, 65])  # 5 rows
second_differences(model, data, :income, :age;
                   at=40, profile=(education="college", region="urban"))
# → "If everyone were a college graduate in an urban region, how does the income effect vary with age?"

Local derivatives hold the profile variables fixed while the modifier moves by ±δ, so each row is a statement about that profile. Discrete comparisons accept profile too, which runs the comparison once per profile point. A profile value is a counterfactual (everyone's female is set to 0, then to 1), not a subgroup analysis; in a nonlinear model the two differ. For subgroups use groups= (next section). profile must not contain the modifier.

Counterfactual and subgroup second differences

Two questions sound alike and have different answers in a nonlinear model:

  1. Counterfactual: how would the effect of x change if everyone had treated = 1 rather than treated = 0? second_differences(model, data, :x, :treated) sets every row to each level and compares the two AMEs; the other covariates keep their observed values, so the comparison is over the same people.
  2. Subgroup: is the effect of x different among the treated than among the untreated? That compares two different sets of rows, which also differ in their other covariates.

groups= makes strata for the first kind: the counterfactual second difference within each stratum.

m = glm(@formula(y ~ x * treated + x * age + region), df, Binomial(), LogitLink())

# Counterfactual, whole sample: everyone untreated vs everyone treated
second_differences(m, df, :x, :treated)

# The same counterfactual within each region: one row per region, with an over_region column
second_differences(m, df, :x, :treated; groups = :region)
second_differences(m, df, :x, :treated; groups = [:region, (:age, 4)])  # region × age quartile

# A continuous modifier: the average cross-derivative over each region's own rows
second_differences(m, df, :x, :age; groups = :region)

# Subgroup comparison across the observed treatment groups (different rows): the result-level form
r = population_margins(m, df; vars = [:x], groups = :treated)
second_differences(r, :x, :treated)

What each stratum's row means:

CallWithin each stratum
discrete modifier, or levels=[…]every row of the stratum set to each level; difference (or slope) of the stratum's AMEs
at = :observed (default for a continuous modifier)every row's modifier shifted by ±δ: the average of ∂²ŷᵢ/∂x∂m over the stratum's rows
at = :mean / :medianthe derivative at the stratum's own (weighted) mean / median of the modifier (eval_point differs by stratum), as Stata's margins, over() computes at() statistics within each group
at = <number(s)> or a NamedTuplethe derivative at that point, the same point in every stratum
profile = (…)the profile variables set for every row of the stratum; one block per profile point

A stratum's row is exactly what the same call returns on that stratum's rows alone with the same vcov (the averaging is within the stratum). The step δ is the call's (1% of the modifier's SD over all rows, or delta=), the same in every stratum: it is a numerical setting, not part of the estimand. All strata come from one vcov evaluation and their gradients are with respect to the same β, so with include_gradients=true the covariance of two strata's second differences is g₁' Σ g₂; for example, whether the interaction differs between two regions has standard error sqrt((g₁ - g₂)' Σ (g₁ - g₂)).

Rules:

  • the modifier cannot be in groups: a stratum is selected by the observed modifier, which the calculation then overwrites. The error points to the result-level form above for the subgroup comparison;
  • a profile variable (or a held variable of an at NamedTuple) cannot be in groups, for the same reason;
  • a focal variable cannot be in groups unless it is binned ((:x, 4)), as in population_margins;
  • empty strata are skipped. Strata appear in the order population_margins reports them.

Derivative at a point or averaged over the data. at=:mean, at=:median, a number or a vector sets the modifier to that value for everyone and differentiates the resulting AME: the answer is the effect heterogeneity at that point of the modifier. at=:observed (the default) instead shifts the modifier by ±δ for every row, keeping each row's own values of everything else, so the result is the mean over observations of the cross-derivative ∂²ŷᵢ/∂x∂m at each row's own (xᵢ, mᵢ, …): one number for the sample, the way an AME is one number for the sample. The two agree when the AME is linear in the modifier (a linear model, or the link scale of a GLM with a plain interaction) and differ in a nonlinear model. at=:observed costs two population_margins calls per profile point whatever the sample size, and returns eval_point = NaN, modifier_level1/2 = NaN and delta_used (the step).

second_differences(model, data, :income, :age; at = :observed)              # average interaction effect
second_differences(model, data, :income, :age; at = :observed, weights = :sw)

Which comparison you get:

ModifierDefaultAlternative
Binary or categoricalAME difference between levelslevels= to select levels
Continuous (numeric, >2 distinct values)average derivative over the observed values (at=:observed)at= for derivatives at chosen points (:mean, a number, …), levels= for slopes between values
Integer-coded categories (≤ 5 integer values)treated as continuous, with a warningmodifier_type=:categorical

Common error: a local derivative needs a numeric modifier. Giving at with a categorical modifier raises an error that says so; omit at and second_differences(model, data, …) compares the modifier's levels instead.

Advanced Analysis Patterns

Robust Standard Errors

Pass the estimator as vcov, as in population_margins:

using CovarianceMatrices

sd = second_differences(model, data, :x, :treated; vcov=HC1())

For a result you already hold, compute it with the estimator and the second differences follow it:

ames = population_margins(model, data; scenarios=(treated=[0, 1],), type=:effects, vcov=HC1())
sd = second_differences(ames, :x, :treated)

The delta method then uses the robust covariance. The degrees of freedom do not change with vcov: t with the residual df for a linear model (as Stata after regress, vce(robust)), z (df = Inf) otherwise; pass df= to override.

Multiple Testing Considerations

A categorical moderator with many levels, several focal variables or many evaluation points produce many tests. Ask for an adjustment over everything returned:

sd = second_differences(model, data, :x, :education; p_adjust=:holm)
# or :bonferroni, or :bh for false-discovery-rate control

sd[:, [:modifier_level1, :modifier_level2, :p_value, :p_adjusted, :significant]]

p_adjusted follows p_value, and significant is p_adjusted < alpha. The family is every row of the returned table: all variables, contrasts, level pairs, evaluation points and profile strata. To adjust over a different family, compute the pieces separately and adjust the p_value column yourself.

Confidence Levels

alpha (the population_margins keyword) sets both the significance level and the interval: alpha=0.1 gives 90% intervals in ci_lower/ci_upper and significant = p_value < 0.1. For a result you already hold, alpha defaults to the alpha it was computed with.

Methodological Notes

Comparison to Coefficient-Based Interactions

In linear models, second differences equal interaction coefficients:

model_linear = lm(@formula(y ~ x * z), data)          # z coded 0/1
second_differences(model_linear, data, :x, :z).second_diff   # ≈ coef(model_linear)[end]

In nonlinear models, they diverge:

model_logit = glm(@formula(y ~ x * z), data, Binomial(), LogitLink())
second_differences(model_logit, data, :x, :z).second_diff    # ≠ coef(model_logit)[end]
# the second difference is on the probability scale (scale=:response)

This divergence motivates the second-differences framework: to express interactions on the interpretable predicted-outcome scale rather than the coefficient scale.

Relationship to Ai & Norton (2003)

Ai & Norton (2003) demonstrated that in nonlinear models (logit, probit), the interaction effect:

  1. Is not equal to the interaction coefficient
  2. Varies across observations
  3. Can have different signs than the coefficient

Second differences in Margins.jl operationalize this framework by computing population-averaged interaction effects (differences of AMEs), providing delta-method standard errors, and enabling tests of the interaction on the predicted scale.

Reference: Ai, C., & Norton, E. C. (2003). Interaction terms in logit and probit models. Economics Letters, 80(1), 123-129.

Population vs Profile Interpretation

Comparisons of levels use population-averaged marginal effects: AMEs averaged over the sample distribution at each modifier level, appropriate for policy analysis requiring external validity. Local derivatives, and any comparison with a profile, are conditional on the profile you specify: useful for scenario-specific analysis or representative cases.

Significance Testing

Hypothesis tests evaluate H₀: second difference = 0 (no interaction on the predicted scale).

  • A significant second difference means an interaction exists on the predicted outcome scale
  • A significant interaction coefficient means an interaction exists on the coefficient scale

In nonlinear models these are distinct hypotheses; second differences test the one most relevant for applied interpretation.

When the model cannot support the calculation

A second difference asks whether the effect of the focal variable changes with the modifier, so the fitted model has to allow that.

Zero by construction. In a model with an identity link, the effect of x can depend on m only through an interaction term. Without one, the second difference is exactly zero whatever the data say; it is a property of the specification, not an estimate. The same happens when the modifier is not in the model at all (in any model, including a logit). second_differences detects this from the gradient of the difference (it is identically zero, so no parameter uncertainty can move it) and then:

  • reports second_diff = 0, se = 0, significant = false, and NaN for statistic, p_value, ci_lower and ci_upper, instead of p = 1 and an interval [0, 0], which would read as a precise finding of "no interaction";
  • leaves the row out of the p_adjust family, since it is not a test;
  • issues one warning per call that lists the affected variable × modifier pairs and says whether the modifier is missing from the model.

A real interaction term is never flagged, even if its estimated coefficient is close to zero: the test is about the model's structure, not the estimate.

Nonlinear models without an interaction term are not flagged. In a logit, for example, the marginal effect of x changes with m through the link even with no x:m term, which is exactly what second differences measure on the response scale. Such a row is reported normally.

Extrapolation. If numeric levels, at or profile values fall outside the range of that variable in the data, the counterfactual extrapolates the fitted model, and in a nonlinear model the result can be badly wrong. second_differences(model, data, …) warns and lists the values. (A precomputed result carries no data, so this check applies to the model-level form only.)

Derived columns. The modifier is changed by re-evaluating the formula, so a modifier transform written in the formula (y ~ x * m + m^2) follows it, while a precomputed column (m2 = m.^2 in the data, y ~ x * m + m2) is held fixed, which answers a different question ("change m, hold m² fixed"). The model-level form warns when a numeric model column looks like such a transform of the modifier, a profile variable or a focal variable. Write the transform in the formula; see Derived Columns.

All three warnings are suppressed by warn=false. To find the zero-by-construction rows programmatically, use isnan.(sd.p_value).

Error Handling

Common Error Patterns

Modifier not found, or also a focal variable:

second_differences(model, data, :x, :nope)
# → ArgumentError: "Modifier variable :nope not found in data. Available columns: …"

The modifier cannot also be in variables; population_margins rejects a variable that is both a focal variable and a scenario variable.

at and levels together, or at with a categorical modifier:

second_differences(model, data, :x, :age; at=40, levels=[30, 50])
# → ArgumentError: Give either `levels` (compare these modifier values) or `at` (local derivative), not both.
second_differences(model, data, :x, :region; at=1)
# → ArgumentError: `at` (local derivative) applies to a continuous modifier; :region is treated as categorical. …

Fewer than two modifier levels:

second_differences(model, data, :x, :treated; levels=[1])
# → ArgumentError: "Need at least 2 modifier levels to compare, got 1."

For a precomputed result with a single scenario level the message is Need at least 2 modifier levels, found 1 for variable x with contrast dy/dx.

Result varies over more than the modifier (precomputed results):

ames = population_margins(model, data; vars=[:x],
                         scenarios=(treated=[0,1], female=[0,1]), type=:effects)
second_differences(ames, :x, :treated)
# → ArgumentError: "The effects result varies over scenario variable :female as well as the modifier :treated …"

Compute the result over the modifier alone (one call per value of the other variable), or use second_differences(model, data, …; profile=(female=[0, 1],)), which does this for you. A result computed with groups= is different: its group variables define strata, and the second differences are taken within each.

Variable not in the result (precomputed results):

second_differences(ames, :z, :treated)
# → ArgumentError: "Variable :z not found in the effects result (variables: x). Include it in `vars` …"

A covariance matrix passed to a precomputed result:

second_differences(ames, :x, :treated, vcov(other_estimator))
# → ArgumentError: "second_differences(result, variables, modifier, vcov) was removed in Margins 3.0 …"

The result's own covariance is used (ames.inference.vcov). Recompute the result with vcov=other_estimator, or use the model-level form with vcov=.

Validation Workflow

using Statistics: mean

function validate_second_differences(sd::DataFrame)
    if any(isnan.(sd.second_diff)) || any(isinf.(sd.second_diff))
        @warn "NaN or Inf values detected in second differences"
    end
    structural = sum(isnan.(sd.p_value))   # zero by construction: the model has no interaction for that row
    structural > 0 && @info "$structural second difference(s) are zero by construction (no test is possible)"
    println("Significant interactions: $(sum(sd.significant)) / $(nrow(sd))")
    println("Mean absolute second difference: $(mean(abs.(sd.second_diff)))")
    return sd
end

sd = validate_second_differences(second_differences(model, data, :x, :treated))

Performance Considerations

The cost is the AME computation. Differencing the AMEs, applying the delta method and forming all pairwise comparisons from the stored gradients is negligible by comparison.

  • Comparison of levels: one population_margins call (all levels in one scenario grid) per profile stratum.
  • Local derivative: two modifier values, so one population_margins call, per evaluation point and stratum.
  • Precomputed results: second_differences(result, …) does no model evaluation and no pass over the data; it reuses the gradient matrix stored in the EffectsResult, so many comparisons from one result are essentially free.
